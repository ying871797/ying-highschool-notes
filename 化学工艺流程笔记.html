三、预处理

(1)表面处理（NaOH、Na2CO3）

  • ① 去除表面油污 → 碱煮水洗
  • ② 去除表面氧化膜 → 打磨、化学法

(2)研磨、粉碎、喷洒酒精

作用：增大反应接触面积，提高反应速率，提高原料的 浸出率。

(3)浸取

  • ① 水浸：分离水溶性和非水溶性物质
  • ② 醇浸：提取有机物
  • ★ ③ 酸浸：可溶解金属、金属氧化物、盐等
  • ④ 碱浸：除油、溶解铝及其化合物等

浸出率 （溶解进入溶液的比率）

  • 增大浸取液浓度
  • 升高温度
  • 固体原料研磨成细颗粒，增大接触面积
  • 充分搅拌
  • 延长浸取反应时间

浸出速率 （浸取反应的快慢）

  • 增大浸取液浓度
  • 升高温度
  • 研磨成细颗粒，增大接触面积
  • 充分搅拌

(4)灼烧

  • ① 结构转化 → 使其能溶于酸、碱
    例：煅烧高岭土，使 Al2O3 能溶于酸。
  • ② 除杂 → 除去可燃性杂质
    例：海带提碘，灼烧使有机物分解。

(1) 温度

  • ① 增速率 → 升温，加快化学反应速率
  • ② 防分解 → 防止…受热分解 （H2O2、NH3·H2O、NH4+、HCO3−、HNO3）
  • ③ 防挥发 → 防止…挥发 （盐酸、HNO3、氨水、有机溶剂）
  • ④ 控水解 → 抑制…水解 或 促进…水解，利于… （Mg2+、Fe3+）
  • ⑤ 控平衡 → 升温，平衡…移动，转化率… （ΔH<0 / ΔH>0）
  • ⑥ 控溶解 → 煮沸可除去溶解… 或 增大…溶解度 （水中溶解 O2 / CO2 / 其他）

(2) pH

判据：① 杂质离子 完全沉淀；② 产品（其他）离子 未开始沉淀。

表沉淀完全 pH 参考

Fe2+  ──氧化剂(H2O2)──▶  Fe3+  ──调 pH──▶  3.7 ≤ pH < 4.7 （先氧化再调 pH，使 Fe3+ 完全沉淀而 Cu2+ 不沉淀）

选调 pH 试剂选择（通常调高 pH）

产品来源 = 滤液（结晶）

不引入杂质
例：消耗 H+，产品为 Cu2+，可用 CuO、Cu(OH)2、CuCO3。

产品来源 = 滤渣

可引入杂质（后续将产品过滤，无影响）。

控控 pH 值的作用

  • ① 使某些离子转为沉淀（氢氧化物）
  • ② 抑制（促进）某些离子水解
过量目的：① 充分溶解（另外…）　② 抑制…水解

(3) 保护（防氧化）

  • ① 产品本身易被氧化
  • ② 添加的试剂具有还原性 （SO2、SO32−、S2−、Fe、Fe2+、酸、C）
  • ③ 充惰性气体

(1) 结晶

混合液 → 蒸发浓缩，冷却结晶，过滤，洗涤，干燥

适用：（出现晶膜时）

混合液 → 蒸发结晶，趁热过滤，洗涤，干燥

适用：（有较多晶体时）

粗品(s) —溶解→ —结晶→ 纯品(s)

即 重结晶，用于进一步提纯。

曲线溶解度曲线（原图左侧曲线示意）

  • ① 溶解度随温度变化较大，如 KNO3 →（冷却结晶）
  • ② 带结晶水，如 CuSO4·5H2O
  • ③ 受热易分解，如 NH4Cl
  • ④ 易水解，如…

醇洗用乙醇洗涤的优点

  • ① 乙醇易挥发，便于干燥
  • ② 减少产品溶解损失 或 防止产品结晶时水解
  • ③ 能除去表面的水溶性杂质

(2) 过滤

  • 常温过滤：玻璃仪器（玻璃棒、烧杯、漏斗）
  • 趁热过滤：装置为 金属保温漏斗
  • 加速过滤：抽滤（减压过滤）；装置：抽滤瓶、布氏漏斗

(3) 洗涤

目的：除去晶体表面的可溶性杂质，得到更纯净的沉淀物。

产品在滤渣中

洗涤 → 提高产品 纯度

产品在滤液中

洗涤 → 提高产品 产率

1单剂洗涤剂选择

  • ① 蒸馏水 → 除去 X 表面的杂质，提高产品纯度
  • ② 冰水 → 除去…（同①），降低 X 溶解度，减少溶解损耗，提高产率
  • ③ 饱和溶液 → 除去…，减少溶解损耗，提高产率
  • ④ 有机溶剂 → 除去…，降低 X 的溶解度，减少…，易于干燥

2双剂洗涤（先冰水，后酒精）

  • ① 第一步：正常洗涤
  • ② 第二步目的：除去晶体表面水分

注：使产品易干燥；注：防止…（结合题中信息作答）。

  • ② 氧化性不够
